# My Study Hub

A mobile-friendly installable web app (PWA) for SPC, H&W, ECLT, MATHS, QUANTUM PHYSICS and AMR.

## Features
- Separate workspace for each subject
- Add, edit, complete and delete assignments with deadlines
- Editable notes that autosave in the browser
- Local PDF library (files up to 8 MB each)
- Subject progress tracker
- Installable on Android and basic offline app shell

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `manifest.webmanifest`, `sw.js`, and `icon.svg` to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. Wait for the Pages deployment and open the URL shown there using Chrome on Android.

## Install on Android
Open the published HTTPS URL in Chrome, tap the three-dot menu, then choose Install app or Add to Home screen.

## Important storage note
This first version saves data locally in the browser on the device. It does not sync across devices or provide account-based backups. PDF files are stored in browser local storage, so keep copies of important files elsewhere.
